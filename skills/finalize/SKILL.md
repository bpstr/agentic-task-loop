# Finalize

Convert validated run artifacts into a compact human handoff.

Report status, implementation, changed files, exact validation outcomes, iterations, decisions, review disposition, remaining risks, and focused human-review points. Represent skipped or unavailable checks accurately.

When the task came from Jira, include a concise tracker-ready summary. The runtime decides whether policy and user approval allow posting it.
